# Awesome Midscene

这是 Midscene.js 社区扩展项目的收录页，覆盖不同平台和语言方向。

## 社区项目

该列表正在整理中，以确保收录信息持续可维护。

当前官方组件和示例请参考：
- [Midscene 仓库](https://github.com/web-infra-dev/midscene)
- [Midscene 示例仓库](https://github.com/web-infra-dev/midscene-example)

## 如何贡献

如果你希望收录社区项目，请在 [Midscene 仓库](https://github.com/web-infra-dev/midscene) 提交 issue。

## 收录标准

Awesome Midscene 应当满足：
- 扩展或集成 Midscene.js 功能
- 积极维护中
- 有清晰的文档和使用示例
- 为 Midscene 社区提供价值
