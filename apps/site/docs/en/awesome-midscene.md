# Awesome Midscene

A curated list page for community projects that extend Midscene.js across platforms and languages.

## Community projects

This section is being refreshed to keep entries consistent and maintainable.

For current official components and examples, see:
- [Midscene repository](https://github.com/web-infra-dev/midscene)
- [Midscene example repository](https://github.com/web-infra-dev/midscene-example)

## Contributing

To request inclusion for a community project, open an issue in the [Midscene repository](https://github.com/web-infra-dev/midscene).

## Criteria for inclusion

Projects featured in Awesome Midscene should:
- Extend or integrate with Midscene.js functionality
- Be actively maintained
- Have clear documentation and usage examples
- Provide value to the Midscene community
